# 🎯 COLLECT YOUR GITHUB INFORMATION

To automatically push your pipeline and set up automation, I need a few details.

---

## 📝 Information Needed

Please provide the following:

### 1. **GitHub Username** (Required)
   - Your actual GitHub username
   - Example: `pshij`
   - NOT your email or display name
   - Check at: https://github.com/settings/profile

### 2. **GitHub Email** (Required)
   - Email associated with your GitHub account
   - Used for git commits

### 3. **GitHub Personal Access Token** (Required)
   - Generate at: https://github.com/settings/tokens
   - Click: "Generate new token (classic)"
   - Scopes needed: `repo` (all options checked)
   - Copy the token (shown only once!)
   - Looks like: `ghp_xxxxxxxxxxxxxxxxx`

### 4. **Repository Visibility** (Optional)
   - Public (default) - visible to everyone (good for portfolio)
   - Private - only you can see it

### 5. **Is this your first GitHub repo?** (Optional)
   - Yes / No
   - Helps with any special setup

---

## 🔐 Security

- Your token is used ONLY to push code
- I don't store tokens
- Token can be revoked anytime from GitHub
- Use `repo` scope only (minimal permissions)
